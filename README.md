# Telegram Test Bot 🤖

Бот для прохождения тестов с административной панелью управления.

## Функционал

### Для пользователей 👤
- **Регистрация**: Имя, фамилия, отчество, номер телефона
- **Прохождение тестов**: Выбор категории → выбор теста → вопросы по одному
- **Результаты**: Процент правильности, детальные ответы
- **Поддержка**: Связь с администраторами

### Для администраторов 👑
- **Управление категориями**: Добавление, удаление
- **Управление тестами**: Добавление, удаление, редактирование
- **Управление вопросами**: Текст вопросов, изображения
- **Управление ответами**: Варианты ответов, правильные ответы
- **Статистика**: Пройденные тесты, активность пользователей
- **Рассылка**: Отправка сообщений всем пользователям
- **Блокировка пользователей**: По номеру телефона

## Установка и запуск

### 1. Клонирование репозитория
```bash
git clone <repository-url>
cd telegrambot-template
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Настройка базы данных
Создайте MySQL базу данных и настройте подключение в файле `.env`:

```env
botTOKEN=your_bot_token_here
mysqlHost=localhost
mysqlUser=root
mysqlPassword=your_password
mysqlDatabase=test_bot_db
logsGroupID=-1001234567890  # опционально
```

### 4. Запуск бота
```bash
python main.py
```

## Использование

### Добавление первого администратора
После запуска бота, первый пользователь, написавший `/admin`, станет администратором.

### Создание тестов
1. Войдите в админ-панель командой `/admin`
2. Создайте категорию
3. Создайте тест в категории
4. Добавьте вопросы к тесту
5. Добавьте варианты ответов к вопросам

### Регистрация пользователей
Пользователи автоматически регистрируются при первом запуске и проходят процесс заполнения профиля.

## Команды

- `/start` - Запуск бота и регистрация
- `/menu` - Возврат в главное меню
- `/admin` - Вход в админ-панель (только для админов)

## Технологии

- **aiogram** - Фреймворк для Telegram ботов
- **MySQL** - База данных
- **python-dotenv** - Загрузка переменных окружения
- **FSM** - Конечные автоматы для управления состояниями

## Разработка

Для разработки рекомендуется использовать виртуальное окружение:

```bash
python -m venv venv
source venv/bin/activate  # для Linux/Mac
# или
venv\Scripts\activate     # для Windows

pip install -r requirements.txt
```
